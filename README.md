## EmailJS Configuration

To enable the contact form functionality, configure **EmailJS** with your credentials.

Replace these values in your JavaScript:

```javascript
emailjs.init("YOUR_PUBLIC_KEY");

emailjs.send(
  "YOUR_SERVICE_ID",
  "YOUR_TEMPLATE_ID",
  templateParams
);
```

Required template variables:

```text
{{from_name}}
{{from_email}}
{{subject}}
{{message}}
```
